## Setup

To **clone this repo**, run:
```
git clone https://github.com/raihaniqbal24/KeilaTheCat.git
cd KeilaTheCat
```

After cloning the repository, **install dependencies** by executing:
```
npm install
```

**Run the server** by executing:
```
npm run dev
```
